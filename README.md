# BetterWindowsThumbnails releases

Installers for BetterWindowsThumbnails: first-frame video thumbnails in Windows Explorer, including online-only
OneDrive and iCloud videos, and thumbnails that Windows no longer purges.

Download the MSI from [Releases](../../releases). Each release has the MSI and its `.sha256` checksum.
Installed versions check this repo once a day and offer new releases themselves (this can be turned off in the
settings window, under Updates).

This repo holds releases only; the source code is not here.
